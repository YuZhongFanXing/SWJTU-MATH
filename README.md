# 西南交通大学数学学院考题资料库

欢迎来到西南交通大学数学学院考题资料库！

本资料库收集整理了西南交通大学数学学院的各类考试资料、课程笔记、考研真题等学习资源，旨在帮助同学们更好地学习和复习。

## 资料分类

| 目录 | 内容说明 |
|------|----------|
| `C++/` | C++ 课程复习提纲、题库 |
| `实变函数/` | 实变函数相关学习资料 |
| `拓扑/` | 拓扑学期中、期末试卷 |
| `推免/` | 推免相关政策文件、毕业去向 |
| `数值分析/` | 数值分析课堂笔记、MATLAB代码 |
| `考研真题/` | 考研数学一历年真题及解析 |
| `政策文件/` | 学院相关政策文件整理 |

## 资料来源

本资料库中的所有资料均来源于公开资料整理收集。如存在侵权行为，请通过 [Issues](https://github.com/YuZhongFanXing/SWJTU-MATH/issues) 反馈，我们将及时处理。
