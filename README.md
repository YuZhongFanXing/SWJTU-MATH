# 西南交通大学数学学院考题资料库

欢迎来到西南交通大学数学学院考题资料库！

本资料库收集整理了西南交通大学数学学院的各类考试资料、课程笔记、考研真题等学习资源，旨在帮助同学们更好地学习和复习。

## 资料分类

| 目录 | 内容说明 |
|------|----------|
| `C++/` | C++ 课程复习提纲、题库 |
| `常微分/` | 常微分方程期中期末试卷 |
| `思修/` | 思想道德与法治复习资料、题库 |
| `实变函数/` | 实变函数相关学习资料 |
| `拓扑/` | 拓扑学期中、期末试卷 |
| `推免/` | 推免相关政策文件、毕业去向 |
| `数值分析/` | 数值分析课堂笔记、MATLAB代码 |
| `概率论/` | 概率论期中考试答案、复习资料 |
| `焚决/` | 数学学院推免细则、通关秘笈 |
| `考研真题/` | 考研数学一历年真题及解析 |
| `政策文件/` | 学院相关政策文件整理 |

## 资料来源

本资料库中的所有资料均来源于公开资料整理收集。如存在侵权行为，请通过 [Issues](https://github.com/YuZhongFanXing/SWJTU-MATH/issues) 反馈，我们将及时处理。

## 贡献方式

欢迎同学们贡献资料，共同完善这个资料库！

### 方式一：GitHub Pull Request

1. Fork 本仓库
2. 上传你的文件
3. 提交 Pull Request

### 方式二：直接联系

如果你不熟悉 GitHub 操作，也可以通过以下方式提交资料：

- 在 [Issues](https://github.com/YuZhongFanXing/SWJTU-MATH/issues) 中留言
- 通过 QQ 群联系管理员（欢迎添加学习交流群）
